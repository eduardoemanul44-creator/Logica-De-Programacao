## Sobre

Repositório com exercícios e projetos de lógica de programação desenvolvidos durante o curso técnico de Desenvolvimento de Sistemas (SENAI/SC), com foco em Python, JavaScript e HTML. Inclui simulações de sistemas reais — máquina de vendas, calculadora de descontos, RPG em texto, notificação automática de notas — praticando condicionais, loops, estruturas de dados e manipulação do DOM.

## Como Executar

**Scripts Python** (requer Python 3):

```bash
python exercicios-logica.py
python maquina-de-vendas.py
```

**Scripts JavaScript** (requer Node.js e o pacote prompt-sync):

```bash
npm install prompt-sync
node cardapio-carrinho.js
node sistema-de-notas.js
```

**Projetos HTML**: basta abrir o arquivo `.html` direto no navegador.

**Apps Script**: cole o código no editor do Google Apps Script (Extensões > Apps Script) de uma planilha com colunas Nome, Email e Nota.
